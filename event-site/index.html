Una biblioteca que circula

Trueque IUB

Un espacio para darle una segunda vida a los libros y conectar a la comunidad universitaria. Hoy presentamos el catálogo, el registro de solicitudes y el procedimiento de revisión y entrega.

Abrir catálogo y solicitud Ficha de registro asistido

El catálogo web de esta demostración contiene ejemplares sintéticos de prueba. No representa todavía el inventario real de la biblioteca ni habilita ejemplares para entrega inmediata.

Cómo participar

  1. Explora el catálogo.
    Consulta los ejemplares publicados y elige el libro que deseas recibir.
  2. Presenta tu propuesta.
    Registra los datos del libro que ofreces, tu información de contacto y autoriza el tratamiento de datos.
  3. Recibe el código.
    Guarda el código y la clave de consulta para seguir el estado de tu solicitud.
  4. Espera la revisión.
    El equipo autorizado revisa la solicitud y decide si continúa al proceso de recepción y evaluación.
  5. Coordina la entrega.
    La aprobación no es la entrega. La fecha y el lugar se confirman por el canal institucional.

Reglas claras

  • La solicitud no se aprueba automáticamente: requiere revisión manual.
  • El libro ofrecido se evalúa antes de aceptarse; no todo libro es admisible.
  • Aprobar una solicitud no significa recibir, aceptar, entregar ni habilitar el ejemplar.
  • No se promete disponibilidad inmediata ni se reserva un libro sin confirmación.
  • Los datos personales se tratan de forma confidencial y no se publican.
  • El inventario real de 67 ejemplares sigue en conciliación física; no se presenta como disponible.
Para la jornada de inauguración, el sistema web se usa como demostración con datos sintéticos. Los registros reales de participantes se hacen en la ficha asistida y se entregan al equipo responsable.
